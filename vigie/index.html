L'avance, c'est ta marge sur la semaine

Si tu consommais ton quota hebdo de façon parfaitement régulière, tu en aurais utilisé autant que la part de semaine écoulée. L'avance mesure l'écart avec ce rythme.

Positive en vert : tu as de la réserve. Négative en rouge : à ce rythme, tu atteindras la limite avant le reset.

semaine écoulée = 1 − (reset − maintenant) / 7 j
avance = semaine écoulée × 100 − % semaine utilisé

Exemple : reset dans 2 jours, donc 5 jours sur 7 écoulés, soit 71,4 %. Tu as utilisé 61 % du quota. Avance : 71,4 − 61 = +10,4 %.

Installer Vigie

Il te faut Node.js 18 ou plus récent. Aucune autre dépendance.

Télécharge le script

curl -fsSL https://raw.githubusercontent.com/houzaifahr974-cyber/houzaifahr974-cyber/main/vigie/vigie.mjs -o ~/.claude/vigie.mjs

Ajoute-le à ~/.claude/settings.json

{
  "statusLine": {
    "type": "command",
    "command": "node ~/.claude/vigie.mjs"
  }
}

Si le fichier contient déjà d'autres réglages, ajoute seulement le bloc "statusLine".

Relance Claude Code

La ligne apparaît sous la zone de saisie et se met à jour à chaque message.

Zéro réseau

Le script ne fait aucun appel internet. Il lit seulement ce que Claude Code lui envoie.

Questions fréquentes

Pourquoi je ne vois pas les barres 5 h et Semaine ?

Ces données ne sont envoyées par Claude Code qu'avec un abonnement Claude (Pro ou Max) et une version récente de Claude Code. Avec une clé API, tu vois le modèle, le coût et le contexte, sans les limites.

Ça marche sur Windows ?

Oui, tant que Node.js est installé. Remplace ~ par le chemin complet de ton dossier utilisateur dans la commande et dans settings.json.

Comment désinstaller ?

Retire le bloc "statusLine" de settings.json, puis supprime le fichier ~/.claude/vigie.mjs.

Ça ralentit Claude Code ?

Non. Le script lit un petit JSON et affiche une ligne. Il tourne en quelques millisecondes.
